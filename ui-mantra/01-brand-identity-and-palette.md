# 01. Brand Identity & Palette Guidelines

## 1. Brand Nomenclature Standard

- **Canonical Format:** Always format as **`flatJSON2csv`**.
- **Tagline:** *"ted thought this was functional & fancy"*
- All page headers, tool guides, web interfaces, dialogs, button labels, and CLI help messages must strictly use **`flatJSON2csv`**.

---

## 2. Color Palette Hierarchy

The visual palette delivers an executive, luxurious, and high-craft aesthetic rooted in a deep emerald base, avoiding generic dark-mode gray or neon clutter.

### Primary Base
* **Token:** `--brand-base: rgba(14, 63, 42, 1.00);` (`#0e3f2a` / `#0E3F2A`)
* **Interactive Hover:** `#1b5e3f` / `rgba(27, 94, 63, 1.00)`
* **Active Press:** `#0a2e1f` / `rgba(10, 46, 31, 1.00)`
* **Accent Highlight:** `#2e9165` / `#34D399`

### Backgrounds & Surfaces
* **Canvas / Deep Neutrals:** `#080f0b`, `#090d0b`, `#0d1310` (graphite carrying subtle green undertones)
* **Surfaces & Cards:** `#0f1c15`, `#151f1a`, `#16281e`
* **Hairline Borders:** `rgba(14, 63, 42, 0.45)` or `rgba(255, 255, 255, 0.08)`

### Typography & Readability (WCAG AAA)
* **Primary Text:** `#f0f6f2` / `#ffffff` (crisp off-white meeting `> 7:1` contrast against dark surfaces)
* **Secondary Text:** `#9bb1a4` / `#a3b8ad` (tinted cool sage)
* **Muted Labels & Timestamps:** `#5e7368` / `#6c8577` (soft slate)

### Restrained Semantic Accents
* **Success:** `#2ea043` (dim: `#0e2916`)
* **Warning:** `#d29922` (dim: `#3a2e10`)
* **Error / Destructive:** `#f85149` / `#dc2626` (dim: `#3a1a1a`)
* **Informational:** `#388bfd` (dim: `#0f2238`)
